# AppLab Desktop 0.4 diagnostic development
This branch contains early diagnostic modules only. It is **not a finished 0.4 Windows installer**.

Modules: read-only Chromium DOM probe, CDP network and exception monitor, conservative safe-action classifier, and combined HTML/JSON reporting.

Still required: integrate with Electron IPC and UI, static scanner, automated navigation, screenshots, Windows packaged testing and dependency handling.

Keep main stable until the 0.4 release is tested and explicitly approved.
